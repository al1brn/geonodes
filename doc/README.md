# Legacy documentation snapshots

This directory contains historical generated API pages and developer notes.
The maintained user documentation is in [`../docs/`](../docs/index.md), with
navigation defined by `../mkdocs.yml`. Use those guides for decorators,
`Package`, reconstruction and the current node API.

Developer notes such as `generation.md` remain here and are linked by the
generator's maintenance instructions. Historical API snapshots should be
regenerated from their source rather than individually patched.
